# VoIP basics: dial peers and voice VLANs

Four routers and a switch carrying voice between two sites.

- `configs/`: POTS and VoIP dial peers on the gateways, voice VLANs (521 and 522) on the switch, and RIP routing between sites.
- `captures/sip-call-setup.pcapng`: one complete phone call, from call setup through the RTP voice stream to teardown.
